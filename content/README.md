This is a repo of Angela's pole moves / pole notes.
These files are intended to be read using Obsidian, which is free for download:
https://obsidian.md/
with the community plugin Dataview. Dataview must be enabled with javascript enabled for
the chorey generator to run, as well as the "To Practice" list.

You can use the community plugin "GitHub Gitless Sync" to sync between your devices.
With it, you don't need Git on your mobile device to sync to it.

There is one markdown file per move, including variations, so I remember to practice all variations.
You can used the property "aliases" which add aliases to each markdown file, so you can refer to the same page/file using different names. This is useful for different pole names for the same move.

There is a chorey/freestyle generator (only including dance moves, for now, as that is what I want).

You can write new markdown files which can filter the moves according to your preferences.

Feel free to branch/fork to use this as a template for your own notes.
